Draw filled rect

SPRITE & MAP DRAW
spr(n,x,y,[w,h,fx,fy])
Draw sprite n at x,y. w/h in sprites (default 1). fx/fy=flip
sspr(sx,sy,sw,sh,dx,dy,[dw,dh,fx,fy])
Stretch sprite from spritesheet region to screen rect
map(cx,cy,sx,sy,cw,ch,[layer])
Draw map cells cx,cy (cell coords) to screen sx,sy. layer=flag bitmask filter
TEXT & COLOR
print(str,[x,y,c])
Print string. Without x,y uses cursor + newlines. Returns x after string
color(c)
Set global draw color (0-15)
cursor(x,y,[c])
Set print cursor position and optional color
cls([c])
Clear screen to color c (default 0/black)
CAMERA & CLIP
camera([x,y])
Shift world draw by -x,-y. No args → reset
clip([x,y,w,h])
Set draw clipping rect. No args → reset to full screen
fillp([pat])
Set fill pattern (16-bit). Use 0b prefix for binary literals
PALETTE TRICKS
pal(c0,c1,[p])
Remap color c0 → c1. p=0 draw palette, p=1 screen palette
pal()
Reset all palette remaps
palt(c,t)
Set color c transparent (t=true/false). Default: color 0 is transparent
palt()
Reset transparency (only 0 is transparent)
PRINT SPECIAL CHARS
"\n"
Newline in print string
"\#7" or "\*"
Inline color change in string (char code 7 + color 0-15)
print("hello", 0, 0, 7)
White text at 0,0
TIP: Each char is 4×6px. Screen fits 32 cols × 21 rows of text.

Input — Player 0 & 1

BUTTON FUNCTIONS
btn(b,[p])
Returns true while button b held. p=player (0 or 1)
btnp(b,[p])
Returns true on first press (+ repeat after delay). Good for menus
BUTTON INDICES
0 — ⬅ LEFTArrow Left / S
1 — ➡ RIGHTArrow Right / F
2 — ⬆ UPArrow Up / E
3 — ⬇ DOWNArrow Down / D
4 — ❎ O / ZZ / C / N
5 — 🅾 X / CX / V / M
TIP: Use constants ⬅ ➡ ⬆ ⬇ ❎ 🅾 in the editor instead of numbers.

Audio — SFX (0-63) & Music (0-63)

SOUND EFFECTS
sfx(n,[ch,off,len])
Play sfx n (0-63). ch=-1 auto, off=note offset, len=note count. sfx(-1) stops all
sfx(-1)
Stop all SFX
sfx(-2)
Stop looping SFX on all channels
MUSIC
music(n,[fade,mask])
Play music pattern n. fade=fadeout ms. mask=channel bitmask (1-15)
music(-1)
Stop music
TIP: Channels 0-3. Channel can be reserved for SFX by excluding it from mask.

Map — 128×64 cells, each cell 8×8px sprite

MAP FUNCTIONS
mget(cx,cy)
Get sprite number at map cell cx,cy
mset(cx,cy,n)
Set map cell cx,cy to sprite n
fget(n,[b])
Get sprite flags. No b → returns all 8 flags as bitmask. b=bit index → bool
fset(n,[b,]v)
Set sprite flag. No b → v is bitmask for all flags
TIP: Use fget for collision: if fget(mget(cx,cy),0) then -- solid!
TILEMAP COLLISION PATTERN
-- check tile flag at world pos
function solid(x,y)
local cx = flr(x/8)
local cy = flr(y/8)
return fget(mget(cx,cy), 0)
end

OOP WITH METATABLES
-- define a class
player = {}
player.__index = player
function player:new(x,y)
local o = {x=x,y=y,spd=2}
return setmetatable(o, player)
end

if btn(0) then self.x -= self.spd end
end
-- usage
local p = player:new(64,64)
p:update()
